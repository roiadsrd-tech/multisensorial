# UI Design Variety Rule

- NEVER place two elements/cards with the exact same visual design, borders, backgrounds, and drop shadows stacked directly on top of each other or side-by-side.
- Avoid repetitive "cards stacked on cards" look.
- When highlighting quotes, metrics, or statements next to a container card, do NOT make another identical card with the same border and shadow. Instead, use typographical integration (floating quote, elegant typography, integrated header within the card, or distinctly different layout style).
