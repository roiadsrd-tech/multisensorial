# Workspace Guidelines

## UI & Design Rules
- **NO IDENTICAL ADJACENT/STACKED CARDS**: NEVER place two elements/cards that share the same visual structure (e.g. rounded card + thick borders + offset drop shadows) stacked directly one above the other or right next to each other.
- Vary visual rhythm: Use direct typography, section headers, badges, or integrate text directly inside the main container rather than stacking cloned cards.
- Follow Caveman communication mode (minimal words, direct technical action).
